# LeetCode Solutions 🚀

Welcome to my **LeetCode Solutions** repository!

This repository contains my solutions to various [LeetCode](https://leetcode.com/) problems, covering **Data Structures & Algorithms, SQL, Database, and Pandas**.

I maintain this repository as part of my continuous learning journey, with the goal of improving problem-solving skills, strengthening fundamentals, exploring different approaches, and understanding the trade-offs between solutions.

Rather than focusing only on getting accepted submissions, I also document alternative approaches to deepen my understanding and build a useful reference for future learning.

## 🎯 Repository Goals

- Practice and improve problem-solving skills.
- Strengthen understanding of Data Structures and Algorithms.
- Improve SQL and database querying skills.
- Solve data manipulation and analysis problems using Pandas.
- Explore brute-force, optimized, and alternative approaches.
- Analyze time and space complexity wherever applicable.
- Maintain a personal reference of concepts and solutions.

## 💡 Solution Approaches

Whenever possible, I try to include multiple approaches to solve a problem:

- **Brute Force:** A straightforward approach to understand the problem.
- **Optimized Approach:** An improved solution focusing on efficiency.
- **Alternative Approaches:** Different techniques or methods to achieve the same result.

The objective is to understand not just how to solve a problem, but also why a particular approach works and when it is more suitable.
